## 💡 نظرة عامة ودراسة الجدوى

### هل التصنيع الذاتي (DIY) يستحق؟
- **التكلفة:** الماكينات الجاهزة بنفس الصلابة ومساحة العمل (40×40 سم) تباع في نطاق **2,200 – 3,500 درهم إماراتي**. تكلفة تصنيع هذا المشروع يدوياً تتراوح بين **1,150 – 1,600 درهم إماراتي** (توفير يصل إلى 50%).
- **سهولة الصيانة والتطوير:** عند بنائك للماكينة بنفسك، تفهم كل مسمار وسلك ودرايفر، مما يجعل استبدال أي قطعة أو مضاعفة حجم الماكينة مستقبلاً أمراً في غاية البساطة.
- **المهارات المطلوبة:** لا يتطلب المشروع لحام إلكترونيات دقيق ولا مخرطة معادن؛ التجميع يعتمد كلياً على قطاعات ألومنيوم قياسية (V-Slot) تُربط بمفاتيح ألن ومسامير عادية، وتوصيلات كهربائية مباشرة بمنافذ براغي (Screw Terminals).

## ⚙️ المواصفات الفنية

| البند | المواصفة |
| :--- | :--- |
| **مساحة العمل الفعلية (Working Area)** | 400 مم (X) × 400 مم (Y) × 65 مم (Z) |
| **هيكل الماكينة (Frame)** | قطاعات ألومنيوم V-Slot 2040 صلبة ومقاومة للالتواء |
| **نظام الحركة الخطية (Linear Motion)** | عجلات بلي صلبة (Delrin/Polycarbonate V-Wheels) |
| **نظام نقل الحركة (Drive Mechanism)** | أعمدة قلاووظ T8 Lead Screws مع صواميل نحاسية مضادة للبوش (Anti-Backlash) |
| **المحركات (Motors)** | 4 مواتير خطوة Nema 17 عزم عالي (45-60 N.cm) |
| **وحدة الحفر (CNC Spindle)** | محرك 500W عالي السرعة (Air-Cooled) مع ظرف ER11 كوليت ومبرد هواء هادئ |
| **وحدة التحكم (Controller)** | Arduino Uno R3 + CNC Shield V3 + درايفرات DRV8825 |
| **البرمجيات الثابتة (Firmware)** | GRBL v1.1 مفتوح المصدر وعالي الاعتمادية |
| **مصدر الطاقة (Power Supply)** | مزود طاقة صناعي 24V 15A (360W) + مخرج Spindle مستقل |

## 🔄 فكرة النظام الثلاثي (3-in-1 Modular)

الشاسيه الميكانيكي تم تصميمه ليكون قاعدة موحدة يتم عليها تبديل الرأس الوظيفي بسهولة تامة:

```
                          ┌────────────────────────┐
                          │   قاعدة الحركة المشتركة   │
                          │   (X / Y / Z Frame)    │
                          └───────────┬────────────┘
                                      │
              ┌───────────────────────┼───────────────────────┐
              ▼                       ▼                       ▼
     [ 1. CNC Router ]      [ 2. Cutter Plotter ]     [ 3. 3D Printer ]
     ─────────────────      ─────────────────────     ─────────────────
     • موتور Spindle 500W   • حامل سكينة رولاند       • رأس بثق Hotend
     • حفر وقطع خشب        (Roland Drag Knife)       • تسخين ومروحة تبريد
     • أكريليك، فوم، فيبر   • قص استيكرات وفينيل      • طباعة مجسمات PLA
```

1. **وضع الـ CNC Wood Router (الوضع الأساسي):**
   * رأس حفر 500W ER11 مخصص لنحت الخشب الطبيعي، خشب الـ MDF، ألواح الأكريليك، وتفريغ علب الهدايا ونماذج الوجاهة.
2. **وضع كتر بلوتر الاستيكر (Vinyl Cutter Plotter):**
   * يتم استبدال حامل الراوتر بحامل سكينة رولاند حرة الدوران (Roland Drag Knife Holder ثمنه حوالي 30 درهم).
   * تقوم الماكينة بقص طبقة الفينيل أو الاستيكر بدقة فائقة دون قطع ورق الحماية الخلفي.
3. **وضع الطابعة ثلاثية الأبعاد (3D Printer):**
   * يتم تركيب رأس صهر البلاستيك (Extruder + E3D V6 Hotend) وسطح تسخين (Heated Bed).

## 📚 أدلة المشروع المرفقة

يحتوي المستودع على أدلة تفصيلية تغطي كل مرحلة:
* 📄 **[قائمة المكونات التفصيلية (BOM)](docs/bom.md):** الأسماء الإنجليزية، الأبعاد الدقيقة، وأماكن الشراء (Amazon.ae / AliExpress).
* 🔧 **[دليل التجميع الميكانيكي](docs/mechanical-assembly.md):** خطوات تركيب الهيكل، وزن الزوايا (Squaring)، وضبط العجلات البيضاوية لمنع الاهتزاز.
* ⚡ **[دليل التوصيلات الكهربائية والإلكترونيات](docs/electronics-wiring.md):** توصيل درايفرات المواتير، ضبط جهد المعايرة ($V_{ref}$)، وتوصيل زر الطوارئ وسويتشات الحماية.
* 💻 **[دليل البرمجة والتشغيل (GRBL & Software)](docs/software-setup.md):** تنزيل السوفت وير على الأردوينو، ضبط قيم الخطوات ($100, $101, $102)، وطريقة إرسال الـ G-Code.
* 🔀 **[دليل التحويل للرؤوس المتبادلة (Modular Heads)](docs/modular-heads.md):** كيفية تركيب سكينة البلوتر ورأس الطباعة ثلاثية الأبعاد.

## 🖥️ البرامج ومسار العمل (Software Workflow)

جميع البرامج المستخدمة في تشغيل الماكينة **مجانية بالكامل ومفتوحة المصدر**:

```
[ التصميم والرسم ] ───► [ مسارات القطع (CAM) ] ───► [ الإرسال والتحكم (Sender) ] ───► [ الماكينة CNC ]
  • Inkscape             • Easel (أونلاين وسهل)       • Candle (خفيف ومباشر)              Arduino Uno + GRBL
  • AutoCAD / Corel      • Carbide Create             • Universal Gcode Sender (UGS)
```

1. **الرسم والتصميم (CAD):** يتم رسم النص، الشعار، أو قالب العلبة على برنامج متجهي (مثل **Inkscape** أو **Illustrator** أو **CorelDraw**) وتصديره بصيغة SVG أو DXF.
2. **توليد كود الحركة (CAM):** يتم فتح الملف ببرنامج **Easel** (مجاني للمبتدئين عبر المتصفح) أو **Carbide Create**، وتحديد عمق القطع وقطر الريشة، فيقوم بتوليد ملف **G-Code**.
3. **التشغيل:** يتم فتح برنامج **Candle** على الكمبيوتر المتصل بالماكينة عبر كابل USB، وتصفير المحاور والضغط على **Send**.

## 🚀 خطوات البدء السريعة

1. راجع [دليل المكونات (BOM)](docs/bom.md) وتأكد من توفر القطع وميزانيتها لديك.
2. عند وصول القطع، اتبع [دليل التجميع الميكانيكي](docs/mechanical-assembly.md) لتثبيت الهيكل بدقة.
3. قم بتوصيل الأسلاك وفق [دليل التوصيلات](docs/electronics-wiring.md).
4. حمّل كود GRBL إلى الأردوينو وابدأ أول تجربة رسم بقلم رصاص للتأكد من المقاسات قبل تشغيل ريشة الحفر!
