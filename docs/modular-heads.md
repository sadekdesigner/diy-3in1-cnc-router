# 🔀 دليل التحويل للرؤوس المتبادلة (Modular Heads Guide)

كيف تحول ماكينتك من **CNC Router** لحفر الخشب إلى **Vinyl Cutter Plotter** لقص الاستيكرات، أو **3D Printer** لطباعة المجسمات؟

---

## 1. وضع كتر بلوتر الاستيكر (Vinyl Cutter Plotter Mode)

قص الفينيل والاستيكر لا يحتاج محركاً دواراً ولا رايشة، بل يحتاج سكينة دقيقة جداً تدور بحرية مع اتجاه الحركة:

```
         [ محور Z ينزل بمقدار 0.2 مم فقط ]
                         │
                         ▼
             ┌───────────────────────┐
             │ Roland Blade Holder   │ ◄── (حامل اسطواني بقطر 11.5 مم)
             │ مع رولمان بلي حر     │
             └───────────┬───────────┘
                         │
                         ▼
                    [ سكينة 45° ]
                         │
 ════════════════════════╧══════════════════════════ (طبقة الفينيل 0.08 مم)
 ────────────────────────────────────────────────── (ورقة السيليكون الحامية - لا تُقطع)
```

### طريقة التركيب والعمل:
1. **القطعة المطلوبة:**
   * ابحث عن: `Roland Vinyl Cutter Blade Holder with 45 degree blades`. سعرها حوالي 30 إلى 40 درهم مع طقم سكاكين.
2. **قاعدة التثبيت:**
   * يتم عمل أدابتور أسطواني بسيط (قطره الخارجي 52 مم ليطابق نفس طوق السبيندل، وداخله ثقب بقطر الحامل).
3. **ضبط العمق (Blade Depth Adjustment):**
   * حامل رولاند به سن قلاووظ نحاسي علوي يحدد بروز طرف السكينة المجهري. يجب أن يبرز طرف السن بمقدار سماكة الفينيل فقط (حوالي 0.1 مم).
4. **توليد مسار القص (G-Code):**
   * من برنامج **Inkscape** باستخدام إضافة `J-Tech Photonics Laser Tool` أو إضافة `Gcodetools`.
   * يتم تحديد ارتفاع الحركة السريعة (Safe Z) = 2 مم، وعمق القص (Cut Z) = 0 مم أو -0.1 مم.

---

## 2. وضع الطابعة ثلاثية الأبعاد (3D Printer Conversion Mode)

لتشغيل الماكينة كطابعة ثلاثية الأبعاد:

### التعديلات المطلوبة:
1. **رأس الصهر والبثق (Extruder & Hotend):**
   * طقم `E3D V6 Hotend 24V` مع محرك بثق `Bowden BMG Extruder`.
2. **سطح التسخين (Heated Bed):**
   * لوح ألومنيوم حراري مقاس 220×220 مم أو 300×300 مم بقدرة 24V يثبت فوق طاولة الماكينة لتثبيت طبقات بلاستيك PLA/PETG.
3. **ترقية لوحة التحكم:**
   * الأردوينو Uno مع CNC Shield V3 يدعم 3 محاور فقط (XYZ) ولا يملك مخرج تحكم بحرارة السخان (Mosfet) أو قراءة الثيرميستور.
   * لذلك، عند التحويل الفعلي لطابعة 3D، يتم استبدال كارت الأردوينو بكارت طابعات مخصص مثل **BigTreeTech SKR Mini E3** أو **RAMPS 1.4** (سعره حوالي 90 إلى 130 درهم) الذي يدعم تسخين السرير ورأس الطباعة مع برنامج **Marlin Firmware**.

## 🎯 المقارنة الفنية بين الأوضاع الثلاثة

| الميزة | CNC Wood Router | Vinyl Cutter Plotter | 3D Printer |
| :--- | :--- | :--- | :--- |
| **الرأس المستخدم** | 500W Spindle + ريشة كربيد | حامل سكينة رولاند 45° حرة | E3D V6 Hotend + فوهة 0.4 مم |
| **قوة التحميل الميكانيكي** | عالية (مقاومة احتكاك الخشب) | شبه منعدمة (احتكاك خفيف جداً) | منعدمة (إيداع بلاستيك منصهر) |
| **سرعة الحركة المثالية** | 800 – 1500 مم/دقيقة | 2500 – 4000 مم/دقيقة | 3000 – 6000 مم/دقيقة |
| **لوحة التحكم الموصى بها**| Arduino Uno + CNC Shield | Arduino Uno + CNC Shield | SKR Mini E3 أو RAMPS 1.4 |
| **البرنامج الثابت** | GRBL v1.1 | GRBL v1.1 | Marlin 2.0 |
